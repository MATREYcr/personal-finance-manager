Wrapper around the Lucide icon set — no icon codebase was available, so Lucide (MIT, the standard shadcn/ui pairing) is used via CDN.

```jsx
<Icon name="pencil" size={16} />
<Icon name="trash-2" size={16} />
```

Requires `<script src="https://unpkg.com/lucide@latest"></script>` loaded once in the page `<helmet>`. See ICONOGRAPHY in readme.md.
