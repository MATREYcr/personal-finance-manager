Primary action element — used for form submits, row actions, dialog confirms, and nav CTAs.

```jsx
<Button variant="default">New transaction</Button>
<Button variant="outline" size="sm">Edit</Button>
<Button variant="destructive" size="sm">Delete</Button>
```

Variants: `default` (accent fill, primary actions — used sparingly), `destructive` (delete/remove), `outline` (secondary actions, filter bars), `secondary` (low-emphasis), `ghost` (icon-only row actions), `link` (inline text actions). Sizes: `sm` / `default` / `lg` / `icon`.
